# Brew & Bean • Artisan Coffee House

A modern, high-performance, single-page responsive portfolio website designed for a boutique coffee shop. This project features a modular multi-file architecture, asynchronous dynamic content rendering, an interactive client-side live search menu, a smooth horizontal trending item scroller, a full-screen image lightbox gallery, and a local storage-backed dark mode theme engine.

---

## 🚀 Live Demo & Key Features

*   **Modular Architecture:** Clean separation of concerns (HTML5 for markup, CSS3 for presentation, JavaScript ES6 for behavioral logic).
*   **Dynamic UI Construction:** Menu grids, trending items, and image galleries are dynamically loaded via data arrays in JavaScript, minimizing DOM overhead.
*   **Live Search Filtering:** Real-time filtering algorithm allowing clients to scan through the signature menu items instantly.
*   **Persistent Dark Mode:** Theme switching interface synced directly with browser `localStorage` to retain client preferences across sessions.
*   **Optimized Responsiveness:** Designed using modern CSS Grid, Flexbox, and `clamp()` fluid-typography mechanics to guarantee an adaptive layout across mobile, tablet, and ultra-wide viewport monitors.
*   **Scroll Mechanics:** Features an automated active navbar indicator (Scroll-Spy framework) and a global back-to-top progressive control.

---

## 🛠️ Built With

*   **HTML5** – Semantic structures and structural layout metadata.
*   **CSS3** – Dynamic custom properties (variables), native dark mode states, and media breakpoint structures.
*   **JavaScript (ES6+)** – Encapsulated IIFE execution environment, state listeners, array mapping engines, and performance navigation scroll listeners.
*   **FontAwesome Icons & Google Fonts** – High-fidelity iconography vector sets and optimized typeface rendering.
